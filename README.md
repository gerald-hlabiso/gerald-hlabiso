### 📈 03 — Portfolio Volatility Risk Scanner

A financial-risk analytics workflow connecting Python predictions with adjustable Power BI alerts.

**Highlights**
- Analyzed **204,135 security-date observations across 502 securities**.
- Compared Logistic Regression and XGBoost.
- Selected model achieved **88.6% recall** and **68.7% ROC-AUC** on the final test period.
- Shows the trade-off between detecting volatility events and managing false alerts.

**Tools:** Python • Pandas • Scikit-learn • XGBoost • Power BI • DAX

### 👥 04 — Employee Turnover Risk & Workforce Retention Analytics

A workforce analytics project combining calibrated machine learning with cost-sensitive threshold analysis and a Power BI dashboard.

**Highlights**
- Uses **1,470 fictional employee records**.
- Selected sigmoid-calibrated LASSO Logistic Regression.
- Achieved **0.781 held-out ROC-AUC**.
- Reduced estimated relative cost by **20.3%** under the project's stated assumptions.

**Tools:** Python • Scikit-learn • Power BI • Excel • Probability Calibration

*Educational retention-planning demonstration using synthetic data.*

[📂 Explore Project](https://github.com/gerald-hlabiso/business-analytics-portfolio/tree/main/projects/employee-turnover-workforce-analytics)

### ❤️ 06 — Cost-Sensitive Heart Disease Screening

An educational machine-learning project examining how calibration and decision thresholds affect missed positive cases, false alerts, and relative cost.

**Highlights**
- Model comparison and probability calibration.
- Independent evaluation on a held-out test set.
- The development-selected **0.36 threshold increased relative cost from 15 to 17**, without improving test recall.
- Demonstrates why threshold choices require independent validation.

**Tools:** Python • Scikit-learn • Calibration • Bootstrap Validation

*Educational demonstration; not a diagnostic system.*

[📂 Explore Project](https://github.com/gerald-hlabiso/business-analytics-portfolio/tree/main/projects/cost-sensitive-heart-disease-screening)
